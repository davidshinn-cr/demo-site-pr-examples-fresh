# Product

## Register

product

## Users

CodeRabbit Solutions Architects demonstrating PR Author, PR Reviewer, and Application Security workflows. The fictional application serves purchasing teams working with quotes and invoices.

## Product Purpose

A working multi-tenant quote-to-order web application provides concrete, reproducible changes for example pull requests. The baseline is secure; the flagship branch deliberately introduces review scenarios. The demo-site repository remains the learning platform.

## Brand Personality

Clear, practical, approachable. Follow the official CodeRabbit brand and the repository's mandatory dark-mode requirement.

## Anti-references

Avoid a marketing landing page, fake controls, and a dashboard of decorative metrics. The purchase and invoice workflow is the primary surface.

## Design Principles

- Make the active organization and role explicit.
- Keep amounts and their units unambiguous.
- Make the complete purchase flow usable with synthetic data.
- Preserve reviewable boundaries between routes, services, storage, and consumers.

## Accessibility & Inclusion

Target WCAG AA contrast, native form controls, visible focus, keyboard navigation, responsive tables, and reduced-motion support, following AGENTS.md and the existing demo-site design reference.
